# aptc106_Grupo03_FoodPlease

## Proyecto Taller de Desarrollo Web y Móvil — UNAB

Sistema de gestión de delivery FoodPlease, desarrollado como MVP funcional con CRUD completo.

## Tecnologías
- Python + Flask
- SQLite
- Patrón MVC
- HTML + Jinja2

## Módulos
- Clientes
- Locales
- Repartidores
- Pedidos

## Instalación
1. Clonar el repositorio
2. Instalar dependencias: `pip install flask`
3. Inicializar base de datos: `python database.py`
4. Ejecutar: `python app.py`
5. Abrir navegador en: `http://127.0.0.1:5000`
